# 對話範例

以下以台北時間展示 Draft v2 的預期使用體驗。交易編號僅為範例。

## 1. 中午記共同支出

現在是 2026-08-13 12:10。

```text
小明：切換共同模式

Bot：已切換為共同模式。
     接下來你們兩人的裸記帳會算共同支出。

小明：牛肉麵 150 #約會

Bot：已記帳 #K7M2Q9TX
     共同｜牛肉麵｜150 元
     標籤：食物・午餐（自動）・約會
     時間：2026/08/13 12:10
     付款：小明
```

`食物`是大分類，`午餐`是系統依正餐品項與時間加上的餐別，`約會`是自訂標籤。

約會結束後，任一人傳送 `切換個人模式`，後續裸記帳就會各自歸入傳送者的個人支出。`目前模式`可隨時確認，明確寫 `共同`或`個人`則只覆蓋該筆。

## 2. 咖啡不自動算午餐

現在是 2026-08-13 12:30。

```text
小美：個人 咖啡 80 #工作

Bot：已記帳 #P4V8R3NZ
     個人｜咖啡｜80 元
     標籤：食物・工作
     時間：2026/08/13 12:30
     付款／所有人：小美
```

咖啡屬於食物大分類，但不是正餐，所以不因中午時段被標成午餐。

## 3. 補登日期但時間未知

```text
小明：昨天 牛肉麵 150

Bot：已記帳 #D6J2H5CW
     共同｜牛肉麵｜150 元
     標籤：食物
     時間：2026/08/12（時間未指定）
     付款：小明
```

只有日期時不假裝知道時間，也不自動猜餐別。可以明確補時間或餐別：

```text
小明：昨天 19:30 牛肉麵 150

Bot：已記帳 #T8F3L6QA
     共同｜牛肉麵｜150 元
     標籤：食物・晚餐（自動）
     時間：2026/08/12 19:30
     付款：小明
```

```text
小明：昨天 晚餐 牛肉麵 150 #台南

Bot：已記帳 #W5C9N2KM
     共同｜牛肉麵｜150 元
     標籤：食物・晚餐・台南
     時間：2026/08/12（時間未指定）
     付款：小明
```

## 4. 查詢與修改

```text
小明：查 #K7M2Q9TX

Bot：#K7M2Q9TX｜有效
     共同｜牛肉麵｜150 元
     標籤：食物・午餐（自動）・約會
     時間：2026/08/13 12:10
     付款：小明

小明：改 #K7M2Q9TX 金額 180

Bot：已修改 #K7M2Q9TX
     金額：150 元 → 180 元

小明：加 #K7M2Q9TX 標籤 #台北 #紀念日

Bot：已修改 #K7M2Q9TX
     新增標籤：台北、紀念日

小明：移除 #K7M2Q9TX 標籤 #台北

Bot：已修改 #K7M2Q9TX
     移除標籤：台北

小明：改 #K7M2Q9TX 餐別 無

Bot：已修改 #K7M2Q9TX
     餐別：午餐（自動）→ 無
```

## 5. 個人支出的權限

```text
小明：改 #P4V8R3NZ 金額 100

Bot：這是小美的個人支出，只有所有人可以修改。

小美：改 #P4V8R3NZ 金額 100

Bot：已修改 #P4V8R3NZ
     金額：80 元 → 100 元
```

個人支出不是秘密，但修改、取消與還原只允許目前所有人。

## 6. 取消與還原

```text
小美：取消 #P4V8R3NZ

Bot：已取消 #P4V8R3NZ
     咖啡｜100 元

小美：還原 #P4V8R3NZ

Bot：已還原 #P4V8R3NZ
     個人｜咖啡｜100 元｜食物・工作
```

取消是軟刪除：一般列表與統計不再計入，但所有人仍能查詢及還原。

## 7. 月報與標籤查詢

```text
小明：本月

Bot：2026/08 小明個人支出 2,100 元

     大分類：
     食物             1,200 元
     交通               900 元
```

小美按同一張卡片的「本月報表」時，Bot 會依該次點擊事件的 user ID 顯示小美自己的月報。要看約會共同支出使用 `本月 共同`，要合併查看使用 `本月 全部`。

```text
小明：本月 #約會

Bot：2026/08｜約會
     8 筆｜3,280 元
```

自訂標籤可以重疊，例如同一筆同時有 `約會`和`台南`，所以不同自訂標籤的小計不可直接相加當成月總額。

```text
小明：孝親費 5000

Bot：已記帳 #FAM2XY88
     個人｜孝親費｜5,000 元
     標籤：居家・原生家庭（自動）

小明：爸爸醫藥費 1200

Bot：個人｜爸爸醫藥費｜1,200 元
     標籤：醫療健康・原生家庭（自動）

小明：本月 #原生家庭

Bot：（Flex 報表卡）本月原生家庭相關支出
```

也可以手動加 `#原生家庭`；明確標籤不會因品項文字之後被修改而自動移除。

```text
小明：週報

Bot：（Flex 報表卡）本週 6 筆，合計 2,860 元

小明：找 牛肉麵

Bot：（Flex 列表卡）搜尋「牛肉麵」：3 筆

小明：分類排行

Bot：（Flex 排行卡）#1 食物、#2 交通、#3 娛樂
```

也可使用 `本週`、`這週`、`上週`、`月報`、`上月`、`搜尋 關鍵字`；報表卡底部可直接點選常用查詢。

## 8. LINE 編輯與收回

若使用者直接編輯一則已入帳的 LINE 訊息：

```text
Bot：原帳目未變更；請使用「改 #K7M2Q9TX 欄位 新值」。
```

若使用者收回原始新增訊息，系統會清除對應帳目，使它不可查詢或還原。若只是不要計入統計、但希望保留紀錄，應使用 `取消 #編號`。

Bot 先前發出的確認訊息可能仍留在 LINE 群組中，系統無法代替使用者移除它。

## 9. 說明指令

```text
小明：說明

Bot：新增：牛肉麵 150 #約會
     個人：個人 咖啡 80
     查詢：最近、週報、本月、找 關鍵字、分類排行、查 #編號
     修改：改 #編號 金額 180
     取消：取消 #編號
     更多：輸入「分類」或「標籤」
```

LINE 實際回覆為三張可橫滑的 Flex 說明卡，並提供「最近紀錄」、「本月報表」、「本週報表」與「分類排行」等 message action。
